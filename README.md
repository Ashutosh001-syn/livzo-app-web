# LivZo

Premium live streaming platform boilerplate built with Next.js 15, TypeScript, Tailwind CSS, Framer Motion, GSAP, and Lenis.

## Commands

```bash
npm run dev
npm run build
npm start
npm run lint
npx tsc --noEmit
```

See [ARCHITECTURE.md](ARCHITECTURE.md) for ownership boundaries and animation strategy.

## Getting Started

Run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

Open [http://localhost:3000](http://localhost:3000) to view the app.
